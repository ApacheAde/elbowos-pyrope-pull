# Pyrope Pull

Full-colour Python 3 neon magnet arcade for ElbowOS.

Steer a polarity-flipping lodestone. Attract gold orbs, repel violet hazards.
A / D move. Space flips polarity (cyan attract / magenta repel).

## Play
```
pip install -r requirements.txt
python3 pyrope_pull.py --play
```

## Record a 9:16 reel
```
python3 pyrope_pull.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
